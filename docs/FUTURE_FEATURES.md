# Future Features & Roadmap

A summary of what is already built in Motive and what is planned for future updates.

## Completed Features

- [x] Full multiplayer game loop (Lobby to Game Over).
- [x] 4–12 player dynamic role balancing.
- [x] Core roles: Mafia, Detective, Doctor, and Villager.
- [x] Secret server-authoritative state filtering.
- [x] Day voting with runoff tie-breaker logic.
- [x] Automatic phase timers and pause/resume controls.
- [x] Reconnect recovery with persistent session tokens.
- [x] Single-player offline bot practice mode.
- [x] Rate limiting, input sanitization, and security defenses.

## Planned Features

- [ ] **Custom Role Packs**: Additional roles like Jester, Vigilante, and Bodyguard.
- [ ] **In-Game Text Chat**: Private Mafia chat at night and public town chat during the day.
- [ ] **Sound Effects & Voice**: Audio cues for night transitions, clock ticks, and elimination gongs.
- [ ] **Match History & Stats**: Personal player stats (win rate, favorite role, survival rate).
- [ ] **Custom Avatars**: Player avatar customization and theme selection.
