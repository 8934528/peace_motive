# Keyboard Shortcuts & Controls

Motive provides accessible keyboard shortcuts and quick controls to make hosting and playing fast and comfortable.

## Keyboard Shortcuts

All hotkeys use the `Ctrl` key to avoid accidental keystrokes:

| Shortcut | Action | Where |
|---|---|---|
| **Ctrl + K** | Open game settings modal | Inside a game room |
| **Ctrl + S** | Save settings modal | While settings modal is open |
| **Ctrl + Enter** | Submit active action or confirm modal | Forms, night actions, votes |

## Host Quick Actions

Hosts have quick buttons with confirmation dialogs:

- **Copy Code**: Copies the 6-character room code or invite link.
- **Pause / Resume**: Pauses or resumes the phase countdown timer.
- **Settings**: Opens the game settings modal to adjust timers and rules.
- **Remove Player**: Kicks an inactive or unwanted player from the room.
- **Restart Game**: Returns all players back to the lobby for another round.
- **End Game**: Immediately concludes the active match.
- **Delete Room**: Soft-deletes the game lobby.

## Player Actions

- **Role Eye Icon**: Review your secret role card and abilities anytime during a match.
- **Leave Game**: Exit the current game room.
- **Sign Out**: Clear your saved local user session.
