# Roles Guide

Motive features four core roles. Each role has distinct abilities and winning goals.

## Core Roles

### 1. Mafia (`MAFIA`)

- **Team**: Mafia
- **Ability**: Selects one living player to eliminate each night.
- **Secret Knowledge**: Sees the names of all Mafia teammates and their night targets.
- **Goal**: Eliminate Town players until Mafia holds equal or greater numbers.

### 2. Doctor (`DOCTOR`)

- **Team**: Town
- **Ability**: Protects one living player each night. If that player is attacked by the Mafia, they survive.
- **Settings**: The host can choose whether Doctors can save themselves or save the same person on consecutive nights.
- **Goal**: Keep town members alive and help eliminate all Mafia.

### 3. Detective (`DETECTIVE`)

- **Team**: Town
- **Ability**: Investigates one living player each night.
- **Result**: Privately learns whether the target is `MAFIA` or `NOT MAFIA`.
- **Goal**: Use investigation results during day discussions to help the Town find suspects.

### 4. Villager (`VILLAGER`)

- **Team**: Town
- **Ability**: No night power.
- **Strength**: Uses careful observation, deduction, and daytime voting to root out the Mafia.
- **Goal**: Identify and eliminate all Mafia members.
